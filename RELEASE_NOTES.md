Readable search results.

**New in Alpha 0.4.0**
- Results are grouped the way desktop Soulseek clients show them: the user sharing (free slot or queue length, upload speed), then each folder, then the files in it with size, bitrate and length
- Little icons tell users, folders and files apart
- Select a user to open their menu, a folder to download the whole thing (it asks first), or a file to download it
- Users with a free slot come first, then the fastest ones

**Install:** copy `SlskME.jar` to the phone and open it (or use the `.jad` for OTA). Uninstall the previous version first.
