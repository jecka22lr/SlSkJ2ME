# lib/j2me-api.jar

Compile-time stubs for CLDC 1.1, MIDP 2.0 and JSR-75 (FileConnection). Every method
throws; it only exists so the compiler knows exactly what the phone provides.

Generated by `tools/gen-api-stubs.py` from MicroEmulator's API signature files
(`api/cldcapi11` and `api/midpapi20`, LGPL 2.1 / Apache 2.0) plus MicroEmulator's
JSR-75 interfaces. To regenerate:

    git clone --depth 1 https://github.com/tisoft/microemu.git
    python3 tools/gen-api-stubs.py stubsrc \
      microemu/microemulator/api/cldcapi11/src/test/resources/cldcapi11-signature.xml \
      microemu/microemulator/api/midpapi20/src/test/resources/midpapi20-signature.xml
    # copy microemu-extensions/microemu-jsr-75/.../javax/microedition/io/file/*.java into stubsrc,
    # replace FileSystemRegistry with a stub, then:
    ecj -source 1.3 -target 1.1 -bootclasspath stubcls -sourcepath stubsrc -d stubcls $(find stubsrc -name '*.java')

Using a real WTK or Nokia SDK jar instead works too.
